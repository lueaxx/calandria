The problem is arithmetic, not technology

Nerdearla runs more than thirty talks in English, many of them at the same time. Commercial live captioning is priced per stage and operated by hand, so accessibility stops being a decision about people and becomes a decision about budget. Most conferences make the obvious call and go without.

Calandria exists so that call doesn't have to be made. It captions a stage for USD 0.65 an hour and tells you what it is spending while it spends it.

Latency and cost measured on six minutes of a real Nerdearla talk — an audience, laughter, an accented speaker. Accuracy measured against a written script, so the number means something.

Audio is expensive. Text is not.

Most approaches send the audio to a model once for every output language. Calandria transcribes it once and translates the resulting text, which is why a fourth language costs almost nothing and why ten stages is a budget line rather than a proposal.

Built for the day, not the demo

What goes wrong at an eventWhat Calandria does
A transcription session ends after ten minutes. Talks run forty. Opens the next session early, feeds both the same audio for a few seconds, and stitches the seam. The audience sees nothing; the dashboard counts a rotation.
The streaming connection fails mid-keynote. Falls back to chunked transcription rather than going quiet. Worse latency, still captions, and the stage is marked degraded.
The speaker never pauses, so nothing is ever finalised. Commits sentences itself once the model has moved past them. Translation fires per sentence instead of per pause — seconds instead of tens of seconds.
Nobody knows what it is costing until the invoice. A running total per stage, and a box that extrapolates the measured rate to any number of stages and hours.
Someone in row 12 has one bar of signal. Their captions degrade and nobody else's do. A slow reader can never stall a stage.

Three surfaces, no build step

The audience opens a page, picks a stage and a language, and reads. Text size and theme persist. Scroll back to re-read what you missed — obvious, and missing from every tool we looked at.

The stream gets a transparent overlay as an OBS or vMix browser source, configured entirely by query string, because an operator sets it up in a dialog with nowhere to click but a URL bar.

The production team gets latency against a one-second budget, errors, rotations, and dollars. Green means the room is keeping up with the speaker.

And when a talk ends, an SRT file, so the recording is subtitled too — in every language the event ran.

Try it without an account

Calandria ships a transcription backend that replays a script instead of calling a model. The whole system runs on it, so you can watch it work before deciding whether to sign up for anything.

git clone https://github.com/lueaxx/calandria
cd calandria
docker compose --profile demo up demo-offline

Then add a key and point it at a real stage. Apache 2.0, so fork it, run it at your event, and change whatever you need.
